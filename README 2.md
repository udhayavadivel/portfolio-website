# Futuristic AI-Inspired Portfolio — Udhayakumar P

A production-ready, fully responsive, futuristic AI-inspired portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **React Three Fiber (Three.js)**.

---

## 🚀 Features

- 🌌 **3D Hero Scene**: Interactive 3D scene with rotating wireframe globe, floating data cubes, pulsing neural network nodes with glowing connections, and mouse-responsive 3D camera movement powered by React Three Fiber & Drei.
- 🎨 **Futuristic UI/UX**: Dark theme with neon cyan (`#00f5ff`), blue (`#0066ff`), and purple (`#8b5cf6`) accents, glassmorphism card surfaces, and dynamic gradient borders.
- 🌓 **Dark / Light Mode**: Smooth theme toggling with persistent state stored in `localStorage`.
- ⌨️ **Dynamic Typing Animation**: Interactive role rotator highlighting Data Analytics, Data Science, AI Engineering, and Generative AI.
- 📊 **Comprehensive Sections**:
  - **Hero**: Name, title, subtitle, interactive 3D hero scene, and CTA buttons (View Projects, Contact Me, Download Resume).
  - **About Me**: Professional background in data analytics, data science, and AI/ML, cyber code visualization, and key metrics.
  - **Skills & Expertise**: Categorized skills (Languages & Tools, Data Science & ML, Generative AI) with animated progress bars.
  - **Featured Projects**: Filterable project gallery (All, Data Analytics, Data Science, Generative AI) with 3D glass cards, GitHub source links, and live demo buttons.
  - **Experience**: Alternating vertical timeline detailing achievements, metrics, and technology stacks.
  - **Certifications**: Grid of credentials from Google, IBM, DeepLearning.AI, Microsoft, and Udemy with verified links.
  - **GitHub Stats**: Clean activity dashboard with repository and contribution metrics.
  - **Testimonials**: Desktop multi-card showcase and mobile interactive carousel with swipe/arrow navigation.
  - **Contact**: Glassmorphic form with validation (React Hook Form), direct contact details, and social links.
  - **AI Chat Assistant Widget**: Floating interactive AI bot with instant quick actions (Skills, Projects, Experience, Contact) and keyword understanding.
- 🎯 **Interactive Extras**:
  - Custom neon glowing cursor with hover-magnification on links and buttons.
  - Top scroll progress indicator bar.
  - Floating back-to-top button with smooth scroll.
  - Background particle constellation canvas.
  - AI initialization loading overlay screen with orbital rings.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/) + [@react-three/drei](https://github.com/pmndrs/drei)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Form Handling**: [React Hook Form](https://react-hook-form.com/)

## 💻 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) (version 18.17 or later).

### Installation

```bash
# Install dependencies
npm install
# or
yarn install
# or
pnpm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Production Build

```bash
npm run build
npm start
```
